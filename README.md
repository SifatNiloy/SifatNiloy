## About Me

I’m a **Software Engineer based in Dhaka** specializing in **Backend Architecture, AI/LLM Engineering, and Full-Stack Systems**. I started my career focused on backend infrastructure and expanded across mobile, real-time systems, and production AI—allowing me to take products cleanly from database schema and API gateways all the way to responsive user interfaces.

| Pillar | What I Build |
| :--- | :--- |
| **AI & LLM Engineering** | Multi-provider LLM integrations (**OpenAI, Gemini, LLaMA, Qwen**), **RAG** pipelines, vector embeddings, semantic search, and agentic workflows with **LangChain**. |
| **Backend & API Architecture** | High-throughput **FastAPI** & **Node.js** services, API gateway patterns, multi-tenant **JWT/RBAC** authentication, **WebSockets**, and low-latency streaming responses. |
| **Full-Stack & Mobile** | End-to-end web and mobile applications using **TypeScript**, **Next.js**, and **React Native** with real-time state synchronization. |
| **Data, Storage & DevOps** | Hybrid data layers (**PostgreSQL, MongoDB, Vector DBs, Redis**), **Python** data pipelines (**NumPy, Pandas, EDA**), containerized with **Docker** and automated **CI/CD**. |
