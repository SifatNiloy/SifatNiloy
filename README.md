## About Me

I’m a **Software Engineer based in Dhaka** specializing in **Backend Architecture, AI/LLM Engineering, and Full-Stack Systems**. I started my career focused on backend infrastructure and expanded across mobile, real-time systems, and production AI—allowing me to take products cleanly from database schema and API gateways all the way to responsive user interfaces.

- **AI & LLM Systems:** Designing multi-provider LLM pipelines, retrieval-augmented generation (RAG), semantic search, and agentic workflows.
- **Backend & Distributed APIs:** Architecting API gateways, multi-tenant authentication, real-time messaging, and low-latency streaming services.
- **End-to-End Product Delivery:** Taking applications from data modeling and caching layers through containerized CI/CD deployments to web and mobile interfaces.
